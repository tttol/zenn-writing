## ロジック
以降では「第二火曜日の07:00に起動する」を例にとります。

- 現在日がその月の8日〜14日の間にあること
- 現在日が火曜日であること
- 現在時刻が07:00であること

この３条件をANDで満たすように実装することで、「第二火曜日の7時に起動する」が実現可能です。

🤔「現在日が8〜14日の間にあれば、必ず第二N曜日であると言い切れるの？」

ここが疑わしいですよね。自分も最初疑いました。

順を追って説明します。

まず、第一火曜日について考えましょう。
1週間は7日あるので、第一火曜日は必ずその月の1日から7日の間のどこかに存在します。


![alt text](/images/7days.png)

今日の日付を $d$ とすると、$d$は以下を満たします。

$$
1<=d<=7
$$

第二火曜日は第一火曜日の7日後なので、左右に7を足すと

$$
8<=d<=14
$$

となり、第二火曜日が8日から14日の間に存在することが示されました。

実装自体は平易で、例えばPythonなら以下のように書くことができます。

```py
from datetime import date


def is_second_tuesday(value: date) -> bool:
    return value.weekday() == 1 and 8 <= value.day <= 14

```
第二火曜日以外も同じロジックでカバー可能で、例えば第四木曜日なら22日から28日の間の木曜日を選定すれば良いわけです。
