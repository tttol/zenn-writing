Javaの`-javaagent`オプションについて、理解が浅いので深掘りして調べてみました。


# -javaagentオプション
javaコマンドのオプションの一つです。
以下のようにjarファイルを指定可能です。

```sh
❯ java -javaagent:build/libs/javaagentexample-0.0.1-SNAPSHOT.jar \
    -cp build/classes/java/main com.example.javaagentexample.Main
```

JavaにおけるAgentとは何かというと、Javaアプリケーション本体に手を加えることなくアプリの挙動を観察・変更できる仕組みです。
※AIの文脈におけるAgentとは別物なのでご注意を。

具体的には、

- メソッドの実行時間を計測する
- ログやメトリクスを自動で集める
- クラスロード時にバイトコードを書き換える

などが可能です。

Datadog、NewRelic、OtelなどのAPMはAgentの仕組みを用いています。
Agentによって、アプリ本体のソースコードを書き換えることなく、ログやメトリクスを収集することが可能になります。


# サンプル
サンプルコードと一緒にJava Agentの具体的な挙動をみていきましょう。
以下のリポジトリにまとめました。

https://github.com/tttol/javaagent-example

## Main.java
シンプルなMainクラスです。

https://github.com/tttol/javaagent-example/blob/main/src/main/java/com/example/javaagentexample/Main.java

実行結果は以下の通り、Hello Worldを出力するだけです。

```sh
❯ java -cp build/classes/java/main com.example.javaagentexample.Main
Hello World.
```

## Agent.java
次にAgent側のロジックです。

https://github.com/tttol/javaagent-example/blob/main/src/main/java/com/example/javaagentexample/Agent.java

### premain
-javaagentで渡されたjarファイルの中に実装されたpremain関数が、main関数の前に実行されるようになっています。
ただし、build.gradleで以下のように`'Premain-Class': 'com.example.javaagentexample.Agent'`を指定する必要があります。

https://github.com/tttol/javaagent-example/blob/main/build.gradle#L34-L43

### MainMessageTransformer (implements ClassFileTransformer)
ClassFileTransformerインターフェースを継承したクラスは、Mainクラスのバイトコードを書き換えることが可能です。
Overrideしたtransformメソッドを用いて、`Hello World`を`Hello Agent`に書き換える処理を実装しています。
MainMessageTransformerを、premainメソッドから呼び出すことでバイトコードの書き換えが可能になります。

## Agent.javaをビルドする
-javaagentオプションでAgent .javaを渡すために、Agent.javaをビルドしてjarファイルにします。

```sh
./gradlew jar
```

build/libs/javaagentexample-0.0.1-SNAPSHOT.jarが生成されます。
中身も一応確認しておきましょう。

```sh
# jarの中身をチェック
❯ jar tf build/libs/javaagentexample-0.0.1-SNAPSHOT.jar
META-INF/
META-INF/MANIFEST.MF
com/
com/example/
com/example/javaagentexample/
com/example/javaagentexample/Agent$MainMessageTransformer.class
com/example/javaagentexample/Agent.class
com/example/javaagentexample/Main.class
application.properties
static/
templates/

# MANIFEST.MFのチェック
❯ jar xf build/libs/javaagentexample-0.0.1-SNAPSHOT.jar META-INF/MANIFEST.MF

❯ cat META-INF/MANIFEST.MF
Manifest-Version: 1.0
Premain-Class: com.example.javaagentexample.Agent
Can-Redefine-Classes: false
Can-Retransform-Classes: false
```

build.gradleで指定した`Premain-Class: com.example.javaagentexample.Agent`がMANIFEST.MFに記載されていることが確認できました。

## Agent込みで実行する
先ほどビルドしたjarを使って、Mainクラスを実行してみましょう。

```sh
❯ java -javaagent:build/libs/javaagentexample-0.0.1-SNAPSHOT.jar -cp build/classes/java/main com.example.javaagentexample.Main
Java Agent started.
Agent args: <none>
Main bytecode transformed.
Hello Agent!
```

Agent.javaで仕込んだログが表示され、最後のMainクラスの出力が`Hello Agent!`に書き換えられていますね。
